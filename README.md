# Lumière & Co. Storefront

Premium Shopify OS 2.0 storefront for Lumière & Co., specializing in handcrafted artisanal home fragrances and luxury candles.

## Design System
- **Typography**: Playfair Display (Headings), Inter (Body)
- **Colors**: Warm Cream (`#FDFBF7`), Deep Charcoal (`#1A1A1A`), Muted Gold (`#C5A059`), Soft Sage (`#8A9A86`)

## Architecture
- Shopify Online Store 2.0 (JSON templates, sections everywhere)
- Tailwind CSS for utility-first styling
- Alpine.js for lightweight, reactive components (AJAX Cart)

## Branch Strategy
- `main`: Production-ready code
- `develop`: Integration branch
- `feature/*`: Feature-specific development branches
